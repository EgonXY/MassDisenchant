MassDisenchant v1.1

This update adds a proper window UI and a minimap button, making the addon much easier to use.

Please replace both files in Interface\AddOns\MassDisenchant.

Note: I couldn’t test the new UI on a WoW 1.12 client, so there may still be some layout issues.

What’s new:

Added a full window that can be opened with the minimap button or /md
The window can be moved by dragging the title bar, and Escape closes it
Added quality selection for Green, Blue, and Epic items
Selecting Epic will show a warning before using it
The item list now shows all eligible items in your bags
Items show their icon, quality-coloured name, and current status
You can scroll through the list with the mouse wheel or scrollbar
Hovering over an item shows its normal tooltip
You can click an item to protect it from being disenchanted
Protected items are dimmed and marked as Protected
Clicking a protected item again will unprotect it
Added a Start/Stop button for the disenchanting process
Added a progress bar to show how far the process has gone
Items show their current status: Queued, Working..., Done, or Skipped
Added a status message showing the current item or final result
Added a Refresh button to rescan your bags and clear the skipped list
The item list now updates automatically when your bags change
Added a movable minimap button
Left-clicking the minimap button opens the window
Use /md minimap to show or hide the minimap button

The main goal of this update was to make MassDisenchant easier to control and give you a much better overview of what the addon is doing while it runs.

Feedback and bug reports are welcome, especially if you notice any UI problems on WoW 1.12.
