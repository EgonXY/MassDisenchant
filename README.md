MassDisenchant v1.1

Version 1.1 adds a full UI and minimap button to make MassDisenchant easier to use.

Note: I wasn’t able to test the new layout on a 1.12 client, so the UI may need some adjustments.

Please replace both files in:

Interface\AddOns\MassDisenchant

Features
Full window UI — Open it by clicking the minimap button or typing /md.
Quality selection — Choose the highest quality to disenchant: Green, Blue, or Epic. Epic also displays a warning.
Item list — Shows all eligible items in your bags with icons, quality-coloured names, and status.
Item protection — Click an item to protect it. Protected items are dimmed and marked as Protected.
Start/Stop — Start the disenchanting process or stop it while running.
Progress tracking — A purple progress bar shows the current progress.
Item status — Items show Queued, Working..., Done, or Skipped during a run.
Result messages — Displays the current item or a summary such as Finished: 12 disenchanted, 1 skipped.
Refresh — Rescans your bags and clears the skipped list. Useful after increasing your Enchanting skill.
Automatic updates — The item list automatically updates when your bags change.
Tooltips — Hover over an item to see its normal tooltip.
Minimap button — Left-click to open the window and drag it to reposition it.
Minimap toggle — Use /md minimap to show or hide the minimap button.
What changed?

This update replaces the previous basic interface with a complete window-based UI and adds better control over which items are disenchanted.

You can now select the maximum item quality, protect individual items, see the progress of each item, refresh the list manually, and access everything directly from the minimap button.

Feedback and bug reports are welcome, especially regarding the UI layout on WoW 1.12.
